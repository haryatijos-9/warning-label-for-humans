The funniest single-line safety warning label that should come printed on
every human being — an entry for the make.fun bounty
[Warning Label for Humans: One Line, Big Laugh](https://make.fun/c/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85).

`main.py` writes the label to `/output/entry.txt`:

> WARNING: This human will say 'I'm five minutes away' while still in bed, with no shoes on, and no intention of leaving.

Run it with `python3 main.py`.
